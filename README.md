# 📉 Customer Churn Analysis

This project analyzes customer churn data to understand why customers leave a telecom company. The goal is to identify key factors affecting churn and build a model to predict churn risk.

## 📁 Files in this Repository

- `Customer Churn (1).csv` – The dataset used for analysis.
- `Telco customer churn.ipynb` – Jupyter Notebook with complete data analysis, visualization, and churn prediction.
- `Telco Customer Churn Analysis.pdf` – A summary report of the project and insights.

## 📊 Key Objectives

- Perform Exploratory Data Analysis (EDA)
- Identify important features contributing to churn
- Build and evaluate machine learning models
- Provide actionable business insights

## 🧠 Tools & Libraries Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook
